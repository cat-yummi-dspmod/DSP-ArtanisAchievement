# Artanis Achievement (荣耀贩子)

https://github.com/cat-yummi-dspmod/DSP-ArtanisAchievement

<details>
<summary>English</summary>

Eight Artanis-themed combat achievements. They appear under the "Mod Achievements" button in Statistics → Achievements (from CustomAchievements).

| Achievement | Condition |
|---|---|
| Activating shields! | Icarus regenerates 20,000 shield within 10 seconds. |
| You have done well. | Wipe out a Dark Fog space assault without touching the controls. |
| Well fought. | Destroy a Dark Fog space core with no save loaded and no ship lost in the last 5 minutes. |
| The battle has turned against my warriors. | Lose 152 Precision Drones within 5 minutes. |
| My warriors could not hold. | Lose 152 Attack Drones within 5 minutes. |
| My forces have suffered great loss. | Lose 152 Corvettes within 5 minutes. |
| I must regroup my forces. | Lose 152 Destroyers within 5 minutes. |
| We embrace the glory of battle. | Destroy 50 or more Dark Fog units with a single Energy Shell Burst. |

Details:

- **Shield**: counts regeneration only (the value shown on the mecha panel), not damage taken in between.
- **You have done well**: the assault must target the star system Icarus is in and be seen from its start. Any key, mouse button or scroll wheel during the wave, Icarus dying or leaving the system, or any assaulting unit flying home instead of being destroyed voids it. Moving the mouse alone is allowed.
- **Well fought**: the core must be destroyed in Icarus's star system while an Icarus space fleet is deployed. Only Icarus's Corvettes and Destroyers count as ships. Loading a save restarts the 5 minutes.
- **Losses**: Precision / Attack Drones are ground units, Corvettes / Destroyers are space units. Losses from Icarus and from Battlefield Analysis Bases both count.
- **We embrace the glory of battle**: counts Dark Fog kills (ground or space) whose final hit came from Icarus during the burst and up to half a second after it. A kill by Icarus's other weapons in that window also counts.
- No progress in sandbox mode.
- **Requires** CatAPI and CustomAchievements.

<details>
<summary>中文</summary>

8 个阿塔尼斯主题的战斗成就。在 统计 → 成就 面板点左上角"MOD成就"按钮查看（CustomAchievements 提供）。

| 成就 | 条件 |
|---|---|
| 激活护盾！ | 伊卡洛斯10秒内恢复20000点护盾值。 |
| 大家做得很好 | 伊卡洛斯在没有任何操作的前提下，全灭一次太空黑雾的攻击。 |
| 漂亮的一仗 | 在5分钟内没有读档且没有损失舰船的情况下，消灭一个太空黑雾核心。 |
| 战局对我们的战士太不利了 | 5分钟内阵亡152个精准无人机。 |
| 我的战士们坚持不住了 | 5分钟内阵亡152个攻击无人机。 |
| 我的部队损失惨重 | 5分钟内阵亡152个护卫舰。 |
| 我得重新集结部队 | 5分钟内阵亡152个驱逐舰。 |
| 拥抱战斗的荣耀 | 用能量盾爆破一次性消灭50个以上黑雾单位。 |

判定细节：

- **护盾**：只计回复量（与机甲面板显示的护盾值同单位），期间受到的伤害不扣。
- **大家做得很好**：突袭必须发生在伊卡洛斯所在星系，并且从开始就在场。期间有任何按键、鼠标按键或滚轮，伊卡洛斯阵亡或离开星系，或有突袭单位没被击毁而是飞回巢穴，这一波都不算。只移动鼠标不算操作。
- **漂亮的一仗**：核心须在伊卡洛斯所在星系被摧毁，且伊卡洛斯有太空编队在外作战；"舰船"指伊卡洛斯的护卫舰和驱逐舰。读档会重新开始计算这 5 分钟。
- **阵亡**：精准无人机、攻击无人机是地面单位，护卫舰、驱逐舰是太空单位；伊卡洛斯和战场分析基站的损失都计入。
- **拥抱战斗的荣耀**：统计爆破期间及结束后半秒内、最后一击来自伊卡洛斯的黑雾击杀（地面和太空都算）。这段时间内伊卡洛斯其他武器的击杀也会计入。
- 沙盒模式不推进。
- 需要 **CatAPI** 与 **CustomAchievements**。
